# GEMB variables
Below is a list of variables used by GEMB. 

| Variable                              | Units             | Description                                                                                                                                      |
| ------------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| age                                   | d                 | Mass-weighted mean age, in decimal days, of all mass in a cell (ice/firn matrix plus pore water), measured from column initialization. Snowfall, rain and vapour deposition enter at age 0; meltwater carries the age of the firn it melted from. Accumulates across gemb\_spinup cycles, so for a spun-up run the epoch is the start of spinup.        |
| albedo\_broadband                     | fraction          | Time series of broadband surface albedo (model output).                                                                                          |
| albedo\_density\_threshold            | kg m<sup>-3</sup> | Density threshold below which albedo\_method is applied (Default Inf).                                                                          |
| albedo\_fixed                         | fraction          | Fixed albedo used if albedo\_method="None" or density > threshold.                                                                              |
| albedo\_ice                           | fraction          | Albedo for bare ice (0.2-0.6).                                                                                                                   |
| albedo\_method                        | string            | Scheme: "GardnerSharp", "GreuellKonzelmann", etc.                                                                                                |
| albedo\_snow                          | fraction          | Albedo for fresh snow (0.5-0.95).                                                                                                                |
| aquifer\_depth                       | m                 | Depth to the water table &mdash; the top of the shallowest cell holding more water than irreducible saturation &mdash; in the column saved as output at that instant. NaN when the column holds no standing water, so "dry" stays distinguishable from "water table at the surface". NaN throughout a run at the default runoff\_method "instantaneous", under which no cell can exceed irreducible saturation.        |
| aquifer\_thickness                   | m                 | Total thickness of cells holding standing (super-irreducible) water, i.e. the saturated thickness a borehole would find wet, in the column saved as output at that instant. A cell counts as saturated once it exceeds irreducible by 1e-3 of its pore space, which excludes the negligible over-saturation left by compaction within a timestep; 0 throughout a run at the default runoff\_method "instantaneous".        |
| black\_carbon\_ice                    | ppmw              | black carbon concentration in ice (parts per million by weight).                                                                                                               |
| black\_carbon\_snow                   | ppmw              | black carbon concentration in snow (parts per million by weight).                                                                                                              |
| cloud\_fraction                       | fraction          | Cloud fraction (0-1) for GreuellKonzelmann method.                                                                                               |
| cloud\_optical\_thickness             | dimensionless     |                                                                                                                                                  |
| column\_dzmax                         | m                 | Maximum allowable grid spacing. See Figure 1 of [Gardner et al., 2023](https://doi.org/10.5194/gmd-16-2277-2023)                                                                             |
| column\_dzmin                         | m                 | Minimum allowable grid spacing. See Figure 1 of [Gardner et al., 2023](https://doi.org/10.5194/gmd-16-2277-2023)                                                                             |
| column\_dztop                         | m                 | Initial surface grid spacing. See Figure 1 of [Gardner et al., 2023](https://doi.org/10.5194/gmd-16-2277-2023)                                                                               |
| column\_zmax                          | m                 | Maximum total column depth. See Figure 1 of [Gardner et al., 2023](https://doi.org/10.5194/gmd-16-2277-2023)                                                                                 |
| column\_zmin                          | m                 | Minimum total column depth. See Figure 1 of [Gardner et al., 2023](https://doi.org/10.5194/gmd-16-2277-2023)                                                                                 |
| column\_ztop                          | m                 | Depth of constant grid spacing at the surface. See Figure 1 of [Gardner et al., 2023](https://doi.org/10.5194/gmd-16-2277-2023).                                                             |
| column\_zy                            | m                 | Grid stretching factor for lower layers. See Figure 1 of [Gardner et al., 2023](https://doi.org/10.5194/gmd-16-2277-2023)                                                                    |
| densification\_coeffs\_M01            | string            | Coefficients for Ligtenberg model (e.g., "Gre_RACMO_GS_SW0").                                                                                    |
| densification\_from\_compaction       | m                 | Compaction due to densification.                                                                                                                 |
| densification\_from\_melt             | m                 | Compaction due to melt.                                                                                                                          |
| densification\_method                 | string            | Model: "HerronLangway", "Arthern", "ArthernB", "Barnola1991", "Crocus", "CrocusPure", "GSFC2020", "Simonsen2013", "Ligtenberg".                                                                          |
| density                               | kg m<sup>-3</sup> | Column density.                                                                                                                                  |
| density\_ice                          | kg m<sup>-3</sup> | Density of pure glacier ice (default 917, matching the Community Firn Model and IMAU-FDM).                                                        |
| dz                                    | m                 | Layer thickness profile.                                                                                                                         |
| elevation                             | m                 |                                                                                                                                                  |
| emissivity                            | fraction          | Base longwave emissivity in the range of 0 to 1.                                                                                                 |
| emissivity\_grain\_radius\_large      | fraction          | Emissivity for large grain sizes, in the range of 0 to 1.                                                                                        |
| emissivity\_grain\_radius\_threshold  | mm                | Grain radius threshold for emissivity switching.                                                                                                 |
| emissivity\_method                    | string            | Method: "uniform", "grain_radius_threshold", "grain_radius_w_threshold".                                                                                             |
| evaporation\_condensation             | kg m<sup>-2</sup> | Net vapour mass exchange, accumulated over the output interval: positive is mass gained by the column (condensation/deposition), negative is mass lost (evaporation/sublimation). |
| firn\_air\_content                    | m                 | Total height of all air in the firn column.                                                                                                      |
| firn\_air\_content\_10m                | m                 | Height of air in the top 10 m of the column, the depth-limited form the firn-core literature reports. The cell straddling 10 m contributes in proportion.        |
| firn\_air\_content\_20m                | m                 | Height of air in the top 20 m of the column.                                                                                                     |
| grain\_dendricity                     | fraction          | grain dendricity in the range of 0 to 1.                                                                                                         |
| grain\_growth\_method                 | string            | Dry non-dendritic grain growth: "Arthern" (Arthern et al., 2010 &mdash; **the default**, as shipped by the Community Firn Model; grows at every density), "Marbouty" (Marbouty, 1980 &mdash; temperature-gradient driven, but stops dead above 400 kg m<sup>-3</sup>), or "hybrid" (Marbouty below that ceiling, Arthern at and above it). Wet cells take the Brun branch on every setting.        |
| grain\_radius                         | mm                | Effective grain radius.                                                                                                                                                |
| grain\_sphericity                     | fraction          | grain sphericity in the range of 0 to 1.                                                                                                         |
| heat\_flux\_latent                    | W m<sup>-2</sup>  | Latent heat flux (positive toward surface).                                                                                                      |
| heat\_flux\_sensible                  | W m<sup>-2</sup>  | Sensible heat flux (positive toward surface).                                                                                                    |
| horizontal\_strain\_rate              | yr<sup>-1</sup>   | Horizontal strain rate, the trace of the horizontal strain-rate tensor (&epsilon;&#775;<sub>xx</sub> + &epsilon;&#775;<sub>yy</sub>). Positive is divergence, which thins every layer at constant density; negative is convergence. Default 0, which disables the term.        |
| ice\_slab\_depth                      | m                 | Depth to the top of the shallowest flow-blocking ice slab, in the column saved as output at that instant. NaN when no slab qualifies, so "no slab" stays distinguishable from "slab at the surface".         |
| ice\_slab\_thickness                  | m                 | Total thickness of cells at or above impermeable\_density, whether or not they block flow, in the column saved as output at that instant.                 |
| impermeable\_density                  | kg m<sup>-3</sup> | Density at or above which a cell's pore space is treated as disconnected, so percolating water cannot pass a sufficiently thick run of such cells (default 830). Across the RetMIP models this criterion spans 810 to 917.        |
| impermeable\_thickness                | m                 | Minimum contiguous thickness of cells at or above impermeable\_density for the run to block percolation and route water to runoff (default 0.1). Below this, water passes through: thin lenses are laterally discontinuous at the scale the model represents.        |
| latent\_heat                          | J kg<sup>-1</sup> | Latent heat of vaporization or sublimation used.                                                                                                 |
| latitude                              | degrees           | Geographic coordinate in decimal degrees.                                                                                                                                                 |
| longitude                             | degrees           | Geographic coordinate in decimal degrees.                                                                                                                                               |
| longwave\_downward                    | W m<sup>-2</sup>  | Downward longwave radiation.                                                                                                                     |
| longwave\_net                         | W m<sup>-2</sup>  | Net longwave radiation.                                                                                                                          |
| mass\_added                           | kg m<sup>-2</sup> | Mass added (positive) or removed (negative) by manage\_layers.                                                                                  |
| melt                                  | kg m<sup>-2</sup> | Melt mass                                                                                                                                        |
| new\_snow\_method                     | string            | Fresh snow density model (e.g., :Constant350, :Fausto, :Pahaut). :Pahaut is Pahaut (1975) as Crocus implements it, the one option fitted to alpine seasonal snow rather than to a polar ice sheet &mdash; prefer it for temperate and mid-latitude glaciers.                                                                                            |
| output\_frequency                     | string            | Output resolution: "daily", "monthly", "all", or "last".                                                                                                 |
| output\_padding                       | integer value     | Extra vertical levels for grid resizing (default: 1000).                                                                                         |
| percolation\_depth                    | m                 | Deepest the meltwater wetting front reached during the output interval (an interval maximum, not a mean). Comparable to upward-looking-radar estimates. Zero when no water moved.        |
| precipitation                         | kg m<sup>-2</sup> or mmwe | Mass of precipitation that falls within each time step.                                                                                                                                               |
| pore\_saturation\_max                 | fraction          | Cap on how full a cell may get when water ponds above a barrier, as a fraction of its pore space (default 1.0, i.e. full saturation permitted). Capacity is (density\_ice &minus; density)&middot;pore\_saturation\_max&middot;dz, the same form irreducible retention uses, so water/capacity is the saturation water\_irreducible\_saturation is defined against. Only read when runoff\_method is not "instantaneous".        |
| precipitation\_mean                   | kg m<sup>-2</sup> | Climatologial mean precipitation per time step                                                                                                                                                 |
| pressure\_air                         | Pa                | Air pressure                                                                                                                                     |
| Profile                               | table             | Table output by `model_initialize_profile` and input into `gemb` containing nine variables that describe the initial state of the snow/firn/ice column.                                                                                                                                                 |
| rain                                  | kg m<sup>-2</sup> | Rain mass.                                                                                                                                       |
| rain\_temperature\_threshold          | K                 | Temperature threshold above which precipitation falls as rain.                                                                                   |
| refreeze                              | kg m<sup>-2</sup> | Refrozen mass                                                                                                                                    |
| relative\_humidity                    | percent           | Relative humidity in the range of 0 to 100 percent.                                                                                              |
| run\_prefix                           | string            | Unique run identifier (default: "default").                                                                                                      |
| runoff                                | kg m<sup>-2</sup> | Runoff mass                                                                                                                                      |
| runoff\_method                        | string            | How water that percolation cannot pass leaves the column: "instantaneous" (the default &mdash; blocked water runs off within the time step and no cell can exceed irreducible saturation), "ZuoOerlemans" (a slope-dependent characteristic timescale, &tau; = c<sub>1</sub> + c<sub>2</sub>&middot;exp(&minus;c<sub>3</sub>&middot;S)), or "Darcy" (a saturated-conductivity flux down the slope). The latter two let water pond above a barrier and drain over a finite timescale, which is what makes standing water and firn aquifers representable; both are scaled by surface\_slope.        |
| shortwave\_absorption\_method         |                   | TO BE CHANGED                                                                                                                                    |
| shortwave\_downward                   | W m<sup>-2</sup>  | Downward shortwave radiation.                                                                                                                                                 |
| shortwave\_downward\_diffuse          | W m<sup>-2</sup>  | Downward diffusive shortwave flux.                                                                                                               |
| shortwave\_net                        | W m<sup>-2</sup>  | Net shortwave radiation.                                                                                                                                                 |
| solar\_zenith\_angle                  | degrees           | Solar zenith angle.                                                                                                                              |
| strain\_thinning                      | m                 | Column thickness change from horizontal ice-dynamic strain (positive is thinning). Zero unless horizontal\_strain\_rate is set.                    |
| surface\_roughness\_effective\_ratio  |                   | Ratio of physical surface roughness to effective roughness.                                                                                      |
| surface\_slope                        | m m<sup>-1</sup>  | Surface slope, the lateral hydraulic gradient driving runoff under runoff\_method "ZuoOerlemans" or "Darcy" (default 0, unread under "instantaneous"). A gradient, not degrees: the RetMIP sites span 0 (Summit) to 0.6 degrees (the firn-aquifer site), i.e. 0 to about 0.010 m m<sup>-1</sup>. "Darcy" requires a positive value, since its flux is proportional to the slope.        |
| temperature                           | K                 | Column temperature.                                                                                                                              |
| temperature\_air                      | K                 | Air temperature.                                                                                                                                 |
| temperature\_air\_mean                | K                 | Climatologial average temperature.                                                                                                                |
| temperature\_observation\_height      | m                 | Thermometer height.                                                                                                                              |
| thermal\_conductivity\_method         | string            | Model: "Calonne2019" (Calonne et al., 2019 eq. 5; the default &mdash; a sigmoid blend at 450 kg m<sup>-3</sup> between snow and firn branches, scaled by the temperature-dependent conductivity of ice, and continuous into ice), "Calonne2019Air" (the same equation carrying the air-conductivity ratio on its snow branch, as IMAU-FDM does), "Sturm" (Sturm et al., 1997), "Calonne" (Calonne et al., 2011 &mdash; density only), or "Marchenko2019" (Marchenko et al., 2019 eq. 30, floored at the Calonne 2011 value below their fitted density range). RetMIP recommends the 2019 formulations, and the Community Firn Model and IMAU-FDM both ship one.        |
| thickness\_cumulative                 | m                 | Profile thickness accounting for mass added and subtracted from the system.                                                                      |
| time                                 | datetime           | `DateTime`-indexed times (a `datenum`-style numeric format is also accepted). |
| valid\_profile\_length                |                   | Length of the vertical profile at the instant in time it was saved as output.                                                                    |
| vapor\_pressure                       | Pa                | Vapor pressure.                                                                                                                                  |
| water                                 | kg m<sup>-2</sup> | Pore water                                                                                                                                                 |
| water\_irreducible\_method            | string            | Irreducible water retention: "ColeouLesaffre" (Col&eacute;ou &amp; Lesaffre, 1998 via Langen et al., 2017 eq. 4 &mdash; **the default**; saturation rises as porosity closes, and is zero at and above pore closeoff), or "constant" (a flat water\_irreducible\_saturation at every density). RetMIP recommends a density-dependent form.        |
| water\_irreducible\_saturation        | fraction          | Irreducible water content saturation fraction (0-0.2, default 0.07). Read only when water\_irreducible\_method is "constant".                     |
| wind\_observation\_height             | m                 | Height above the surface where wind is measured or modeled.                                                                                                                  |
| wind\_speed                           | m s<sup>-1</sup>  | Wind speed.                                                                                                                                                 |
| wind\_speed\_mean                     | m s<sup>-1</sup>  | Climatological average wind speed.                                                                                                                                                 |
